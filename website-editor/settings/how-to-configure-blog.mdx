title: "How to Configure Blog Settings"
description: "Set up your blog list page configuration"
---

Configure how your blog list page appears and functions.

## Accessing Blog Config

1. Open your website in the editor
2. Click **Settings** tab
3. Go to **SEO** section
4. Find **Blog Config** area

## Blog Settings

### Blog Path

The URL path for your blog list page:

```
/blog
```

This creates: `yoursite.com/blog`

### Canonical URL

Set the canonical URL for SEO:

```
https://yoursite.com/blog
```

Helps prevent duplicate content issues.

### Blog Heading

The main title on your blog list page:

```
Our Blog
```

Or:

```
Latest Articles
```

### Blog Sub Heading

Description text below the heading:

```
Insights, tips, and updates from our team
```

### Post Order

Choose the order of posts on your blog list:

- **Newest first (date created)**: the default
- **Oldest first (date created)**
- **Recently published first**
- **Least recently published first**
- **Recently edited first**

### Category Colors

Your published categories are listed here with their post counts. Pick a color for each one. The color is used on the blog list, in the category bar, and in the related posts sidebar. Categories you don't set get a default color based on their name.

Use **+ Add category** to set a color before any post uses that category.

### Related Posts Sidebar

When on, each blog post shows more posts from the same category, the list of categories, and a link back to the blog. On phones it appears below the article. It is on by default and works on posts you've already published.

### Menu Links

Add navigation links to your blog page:

- Link text
- Link URL
- Opens in new tab (optional)

## Saving Changes

Click **Save** after making changes. The blog list page updates automatically.

## Categories on the Blog List

When your posts have categories, the blog list shows a category bar under the heading with the number of posts in each one. Visitors click a category to see only its posts.

A post's category is set on the post itself. Use the same spelling on every post: "News" and "news" show up as two separate categories in the bar.

## Blog Post URLs

Individual blog posts have URLs like:

```
yoursite.com/blog/post-title
```

The path is based on the blog post's URL slug.

## Tips

- Use descriptive headings
- Keep sub headings concise
- Set canonical URL for SEO
- Add relevant menu links
- Preview after changes
